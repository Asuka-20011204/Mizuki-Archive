# 2026-09-29 · V2 图片缩略图处理闭环

## 背景

用户确认处理任务需要保持手动触发，并覆盖 PDF 文本提取、TXT/Markdown 提取和图片缩略图；详情页需要能查看任务结果、下载派生产物，文本结果还要参与关键词检索。本轮在已有 MySQL 持久任务和单进程 Worker 基础上增加图片处理，不引入 Redis 或 RabbitMQ。

## 本轮变更

- 增加 `generate_thumbnail` 任务类型和 `thumbnail` 派生产物类型，沿用任务租约、最大尝试次数、来源 SHA-256 校验和幂等创建。
- 新增图片处理器：支持现有上传白名单中的 PNG、JPEG 和 WebP；解码前限制单边 12,000 像素、总像素 4,000 万，输出最大 640×640 的 PNG。
- Worker 按任务类型分发到文本提取或缩略图处理器；缩略图写入 `APP_DATA_DIR/derived`，不覆盖原图。
- 详情页根据资料类型展示“手动提取文本”或“手动生成缩略图”；成功后显示缩略图内联预览和下载链接。
- 派生产物下载接口改为通用下载，新增受会话保护的缩略图内联预览接口；文本派生正文继续参与关键词检索。
- 补充处理器、Service 和 HTTP 路由测试，并更新架构、安全、路线图、README 和前端设计文档。
