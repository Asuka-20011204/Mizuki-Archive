# 2026-09-29 · 资料库动效与空状态重排

## 目的与范围

现有界面动效只在初次加载时整体淡入，资料状态切换没有层次；搜索无结果的文字靠左，与宽大的留白失衡。用户要求更鲜明的高端动画，并审视登录、资料库和详情的视觉平衡。本轮只改 Vue 视图、样式及设计文档，不改 API、权限、资料数据结构或搜索条件。

## 取舍

- 参考本地 Sakurairo 的封面、柔光、环形元素与缓动手感，重新设计为分段揭示、缓慢环绕、扫光、筛选胶囊反馈、列表错峰入场和抽屉过渡；不复用主题代码和素材。
- 无结果与加载状态都在内容面中央排版，保留清晰的标题和操作；筛选后无结果新增清除筛选按钮，清空关键词、类型及并行加入的标签筛选后把焦点送回搜索框；首次空库仍引导上传。
- 动画只作用于装饰与过渡，服务端仍决定查询和收藏结果；尊重 `prefers-reduced-motion`，避免持续位移影响键盘焦点与文字阅读。

## 验证与遗留风险

`npm run build --prefix web` 最终通过 Vue 类型检查与 Vite 构建，`git diff --check` 通过。在独立的合成 API 预览中检查了 1280px 桌面、768px 中屏、320px 窄屏、搜索无结果及清除筛选、详情打开与 Escape 后的焦点返回；各屏宽均无横向溢出。额外发现原手机登录页的大字母挤压标题，已改为居中两行并复测。原有 `5175` 预览是冻结样例，本轮检查使用单独端口的新代码，不能代替真实资料的验收。

构建期间并行开发的标签功能曾短暂产生未使用函数的类型错误；标签界面接入后重新构建已通过。本轮没有擅自改动该功能的实现。

代码评审发现抽屉退出时焦点过早返回，以及列表行的延迟透明度会让可聚焦按钮暂时不可见。现改为抽屉退场结束后恢复焦点、列表行仅位移错峰且全程可见；在合成预览中复核 Escape 退场前后焦点留在抽屉/返回原资料行。

尚未使用真实 MySQL 对上传、下载做本轮回归，也未在系统级“减少动态效果”环境中做浏览器实测；CSS 已为该偏好关闭动效。若视觉反馈认为动效强度或节奏仍不合适，优先调整集中动效文件的时长与层级。
