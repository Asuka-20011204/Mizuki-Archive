# 保存的检索视图

- 日期：2026-09-30
- 目的：让用户复用“课程 PDF”“尚未整理”等组合条件，而不是反复输入或复制搜索结果。

## 实现与边界

- 搜索条件支持关键词、来源、类型、标签和整理状态；空关键词至少还需有类型、标签或整理状态，不提供无限制清单。两类来源仍各自分页、账号归属与软删除规则不变。
- `014` 迁移新增用户范围的视图表与账号内名称唯一索引；每账号最多 30 个视图。保存、列出和删除仅操作条件，应用视图仍实时读取授权资料，删除不触碰文件或卡片。整理状态与卡片链接可用状态分开。
- Vue 在原有搜索面板增加组合筛选、保存名称、打开和确认删除；窄屏单列、可访问标签与错误/成功消息沿用项目自有 Sakura 系风格。

## 验证与遗留

- Go 服务层与 HTTP 测试覆盖无效筛选、空关键词状态检索、账号隔离及视图增删；隔离 MySQL 8.4 对组合条件、跨账号归属、账号内重名、31 个超限、`014` 首次/重复迁移及模拟登记中断重试均通过，临时容器已停止。
- 初次隔离库测试暴露 `013` 回填遗留的 GORM `WHERE` 污染下一版本迁移检查；迁移循环改为同一锁连接上的全新 GORM 会话，随后在全新隔离库重试通过，不掩盖首次失败。
- 前端新增条件预校验 3 个测试用例；`go test ./...`、`go vet ./...`、`npm --prefix web test`（共 11 个前端用例）与 `npm --prefix web run build` 通过。最终差异、敏感文件及暂存区核对在提交前执行；真实浏览器手动操作、窄屏和大数据量查询耗时仍待验收。未经实际投递的大陆手机注册入口仍保持关闭。
