# 2026-09-30 · 私有专题展页

## 目的与边界

将同一账号已收录的文件与外部卡片按主题编排成带封面、简介和有序分区的私有页面，方便重新阅读和分享前的个人梳理；本功能不提供公开分享、不复制资料或站外内容，删除专题不删除原件。产品和权限决定见 [ADR 0014](../decisions/0014-private-topic-pages.md)。

## 设计与取舍

- 沿用 Model/Controller/Service/Repository 和版本化迁移，不使用 GORM AutoMigrate 修改生产表。
- 只引用当前账号可见的资料，封面来自本站图片；分区和条目提供键盘可用的显式排序，不添加拖拽依赖。事务限制数据量并在删除资料时清理引用。
- 这一页是资料库的私有编排视图，不是博客公开页面。视觉参考现有 [设计约束](../design.md)，不复制 Sakurairo 主题源码与素材。
