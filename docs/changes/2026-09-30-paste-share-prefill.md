# 粘贴分享信息预填外部卡片

- 日期：2026-09-30
- 目的：落实路线图 P0 的“粘贴即收录”，减少录入分享链接和提取码的重复输入。

## 范围与取舍

- 新增独立的浏览器文本解析模块和 Node 单元测试；面板的粘贴框可在粘贴时预填，也可点击“解析并预填卡片”。只识别首个 HTTP(S) 链接、显式标题和提取码，用户可继续编辑并手动保存。
- 不请求第三方服务、不自动提交；网盘类型只基于白名单主机名做建议。恶意协议、URL 内嵌登录凭据、过长输入显式拒绝。来源说明和其他非标准文本需要用户手动补充。
- 与已有外部卡片数据结构兼容，不增加表字段或访问权限；在窄屏仍为单列表单。

## 验证与风险

- `npm --prefix web test`：8 个解析测试通过，覆盖网盘信息、纯链接、单行分享、同行提取码、危险协议、凭据、超长内容和中文标题截断。
- `npm --prefix web run build`：Vue TypeScript 类型检查及 Vite 生产构建通过。
- 尚未做真实浏览器粘贴、键盘焦点和双账号隔离回归，不宣称完成浏览器验收；用户提供的链接可信性和可用性仍需人工核对。
