# 已整理资料批量入口

- 日期：2026-09-30
- 目标：补齐 P0 已整理资料的混合来源批量入口，使整理完成后的文件和外部卡片仍可批量维护。

## 范围与取舍

- `OrganizedPanel.vue` 复用现有私有统一搜索的 `organization_status=organized` 筛选，两类来源各 20 项独立分页；只展示未归档资料，翻页和刷新清空选择，每次最多 40 项，不建立新的查询/权限实现。
- 支持批量退回待整理、增删一个标签、收藏/取消收藏、归档及永久删除。危险删除必须输入“删除 N”，文件待清理时不鼓励重试整批；标签/收藏的反向按钮仅针对服务端返回的实际变化项，仍可能覆盖并发修改。退回可在收件箱重新整理，归档可从归档区恢复。
- 使用已有 Sakurairo 风格的白色浮层、双列列表和窄屏单列布局；勾选与详情/编辑分开，确认、空、加载、失败和操作数量有文本反馈。

## 验证

- `npm --prefix web test`：11 项通过；`npm --prefix web run build`：TypeScript 检查和 Vite 构建通过；`go vet ./...`、`go test ./... -count=1` 和 `git diff --check` 通过。未设置隔离实库 DSN，既有实库用例在本轮 Go 测试中跳过；此轮未改数据库或 API。
- 本地 `5173` 和 `8080` 正在监听；浏览器只看到未登录首页，未使用真实或开发账号操作资料。登录后跨页选择、确认/反向恢复、窄屏、错误恢复的手动交互尚未验收，不把构建通过当作端到端验证。

## 风险与下一步

- 搜索服务按来源各 20 项分页，来源多时同一页可能有 40 项；删除、归档或退回后当前页为空则回退一页。已整理视图随其他面板操作重新取数，仍须用真实浏览器核对选中、跨页、反向操作、窄屏与登录态。
- P0 批量操作保持未勾选；后续继续 P1 预览键盘切换等路线图任务，不把其他未完成项折叠进本轮结果。
