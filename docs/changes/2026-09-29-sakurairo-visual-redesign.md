# 2026-09-29 · Sakurairo 视觉改版

## 目标与范围

用户希望 Mizuki Archive 更明亮、大气、高级，明确要求大量参考本地 Sakurairo（Sakura 系）主题的设计语言与动画，而非只借一点颜色，也不希望满屏同构纸片或工作台侧栏。本轮只改 Vue 视图、四份样式及对应文档；登录、筛选、搜索、上传、列表、详情、下载和服务端权限边界均保留。

## 来源与取舍

- 直接检查下载包的 `style.css`、`css/animation.css` 与主题截图，并参照本地主题组件/动效索引。改用宽幅封面、浮动白色胶囊导航、半透明白色内容面、少量柔光阴影与错层入场，主色限制在低饱和蓝绿。
- 保留“资料库”而非博客的内容结构：一块列表面板容纳可扫读的资料行，详情仍是受控模态抽屉；不搬用 WordPress 模板、全局 `transition: all`、樱花粒子或第三方字体/图片。
- 登录后退出仍在顶栏；窄屏筛选用短标签并以 `aria-pressed` 表明选中状态；减少动态效果偏好时关闭动画。

## 验证

- `cd web; npm run build`：Vue 类型检查与 Vite 构建通过。
- 浏览器以合成样例检查桌面登录、资料库及 320px 小屏资料库；小屏无横向溢出。合成服务不读取真实私有资料。

## 遗留风险与下一步

尚未运行 WordPress 主题本身，也未确认其演示站点与本地下载版本完全一致；实际依据以本地 CSS 为准。尚未在本轮新视觉下重新跑真实 MySQL 登录、上传、下载与多浏览器视觉回归。继续检查长文件名、高缩放、键盘全流程和真实数据状态；不把视觉预览当作业务验收。
