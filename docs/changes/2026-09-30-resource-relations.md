# 2026-09-30 · 私有资料关联线索

## 目的与范围

把同一账号的游戏、攻略、截图、说明等已存在文件或外部卡片两两关联，双方详情都能看到对方的名称，并可跳转或解除关系。不引入关系图、第三方抓取或跨账号共享。

## 设计与取舍

- `019_resource_relations.sql` 保存账号、规范化的无方向两端及建立时间；同一对资料唯一，单项最多 100 条。多态端点无法由单个外键覆盖，创建时先按稳定顺序锁住并核验两端，单项和批量删除在同一数据库事务内清理关联。
- `GET /api/relations/:source/:id`、`POST /api/relations`、`DELETE /api/relations/:id` 都要求会话；不存在和跨账号统一返回 404。列表对文件和卡片批量装入当前名称，不做每条一次查询。
- 文件详情与外部卡片编辑表单下方复用关联面板，用已有统一搜索找目标；解除只删除关联记录，不删除原件。搜索候选随详情切换清空，避免显示上一个资料的结果。
- 迁移应由生产独立迁移服务在备份后先执行；应用运行账号无需 DDL 权限。关联数据将来可纳入 P1 可携带导出，目前还不能对外宣称可导出。
