# 多用户身份与邮箱验证码基础（进行中）

- 日期：2026-09-29
- 目的：把项目从单管理员兼容模型推进到多用户私有资料空间，并为邮箱验证码注册/登录提供可测试的加密邮件边界。
- 范围：新增用户/验证码迁移、会话和资料归属、服务端用户上下文、跨用户查询过滤、用户命名空间缓存、SMTP 发送适配器、邮箱注册/登录 API 与前端入口；手机号短信和真实 SMTP 浏览器验收未包含。
- 取舍：先支持标准 SMTP 的 STARTTLS 和 465 隐式 TLS，证书校验和密码认证不能降级；不假设用户已有短信提供方，也不提供将验证码输出到日志的“开发模式”。
- 验证：`go test ./...`、`go vet ./...`、`npm --prefix web run build` 已通过；SMTP 本地模拟覆盖缺少 STARTTLS、非法头和加密交付；真实 MySQL 迁移、跨账号浏览器流程、真实 SMTP 仍待验收。
- 遗留风险：当前迁移的可空归属字段会在 API 启动时回填并收紧；需要在隔离 MySQL 中验证 007/008 重复迁移和旧 007 兼容路径。密码登录仍是迁移期管理员兼容入口。
- 下一步：补充跨用户 HTTP 负例和真实/隔离 MySQL 迁移验收；完成生产 SMTP 配置后浏览器注册、登录、退出和资料隔离回归，再决定手机号服务商。
