# 2026-09-29 · 产品功能 TODO 梳理

## 目的

根据当前资料库的使用方向，记录后续功能候选，避免把产品继续扩展成臃肿的通用工作台。

## 范围

- 将外部资源索引、粘贴即收录、待整理收件箱、批量操作、重复提醒、统一搜索和保存的检索视图列为最高优先级。
- 将快速预览、资源状态、笔记摘录、关联线索和可携带导出列为体验增强项。
- 将专题展页和扫描件 OCR 列为特色及能力扩展项。
- 明确暂不纳入“资料重逢”推荐功能。

## 取舍

- 外部资源只保存用户主动提供的链接和元数据，不自动登录、抓取或下载第三方网盘。
- 重复检测默认只提醒，不自动删除，避免误伤用户资料。
- 关联线索先采用可理解的列表关系，不先做复杂的关系图或新的工作台首页。
- 导出功能需区分“索引导出”和“文件备份”，不把外部链接伪装成已备份文件。

## 验证与遗留

- 本轮仅更新规划文档，没有修改业务代码，也没有新增可声称已实现的功能。
- 后续每个 TODO 需要单独定义数据归属、权限、失败路径、测试和可回退方案后再开发。
