# 收件箱批量整理首个切片

- 日期：2026-09-30
- 目的：在不混入未设计的批量删除/归档语义前，先让当前用户高效整理站内文件和外部卡片。

## 范围和取舍

- `PATCH /api/inbox/batch` 接收最多 50 个明确来源与 ID、目标状态。Service 检查会话、格式、重复和批次规模；GORM 在 MySQL 事务中锁定两表用户行，缺失/越权整批回滚；HTTP 返回所选数量。
- Vue 收件箱支持勾选当前页、最多 50 项、提交前确认数量和成功后单次撤销；撤销写回 `pending`，不会删除原件或更改外部链接状态。
- 不将此切片等同 P0 整体完成：批量加标签、收藏、归档和删除待设计；撤销不具备跨会话版本冲突检测。

- 同一用户在另一设备更改状态后，本页的“撤销”可能覆盖新状态；如要跨会话安全撤销应设计版本号/操作记录。
