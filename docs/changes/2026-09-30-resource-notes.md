# 2026-09-30 · 私人笔记与 PDF 页码摘录

## 目的和范围

补齐路线图 P1 的文件注记：在站内文件详情手动保存私人摘录、正文和来源说明，PDF 可附页码；支持编辑、删除与关键词找回。不会把卡片备注冒充文件笔记，也不从 PDF 自动抽取选择文本。

新增 `018_resource_notes` 迁移、Model/Repository/Service/Controller 分层、详情组件及同源 API。每个操作由服务端会话限定用户与文件，单项/批量删除文件时在同一事务清理笔记；创建用文件行锁限制每文件至多 100 条。对用户输入做长度、页码和控制字符校验，前端用 Vue 文本节点展示，不执行 HTML。代码审查发现并修复编辑对象切换和保存中继续输入造成的草稿丢失路径；安全审查发现在线笔记残留，已改为同步清理。备份留存和大规模子串搜索成本仍是待评估风险。
