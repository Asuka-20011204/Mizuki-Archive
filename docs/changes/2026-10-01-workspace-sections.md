# 2026-10-01 · 后台功能分区导航

## 目的

解决登录后的搜索、收件箱、已整理、归档、外部资源、专题和文件列表全部连续堆叠在一个页面的问题，降低首屏信息密度和误操作风险。

## 范围

- 增加后台一级导航：文件资料、查找、整理、外部资源、专题。
- 将整理拆成待整理、已整理、归档三个子页面。
- 使用 hash 地址支持后台分区直达、刷新恢复和浏览器前进/后退。
- 采用首次访问懒加载；已访问的组件通过 `v-show` 保留，避免切换时丢失外部资源或专题编辑草稿。
- 从待整理/搜索打开外部卡片时自动切换到外部资源页面并聚焦编辑流程。
- 简化文件首页，移除与业务操作无关的重复欢迎封面和统计面板。

## 取舍

- 不新增后端接口、权限或数据模型；每个面板继续使用原有服务端请求和刷新事件。
- 不把详情检查器拆成独立路由，保持从不同分区打开同一资料详情的连续体验。
- 使用地址片段而不是引入路由库，避免为当前单页应用增加新的运行时依赖。

## 验证结果

- `npm run test --prefix web`：20 个测试通过。
- `npm run build --prefix web`：通过，`vue-tsc` 和 Vite 生产构建均成功。
- `git diff --check`：本轮文件通过；Git 换行转换提示不属于格式错误。
- 浏览器视觉回归：本轮 CUA 浏览器工具出现本地资产路径错误，未完成自动化截图；已完成模板、响应式 CSS 和地址状态的静态检查。

## 遗留风险

- 需要在真实登录会话下人工点选七个后台地址，确认各面板的服务端加载、编辑草稿保留和跨分区详情跳转。
- 工作区仍保留原有独立面板的卡片样式，后续可继续统一各分区的密度和标题层级。
