# 2026-09-29 · V1 上传后详情预览修复

## 问题

浏览器文件选择上传成功后，页面会打开详情，但上传函数只把返回的资料对象写入 `selected`，没有复用详情加载流程，因此 TXT/Markdown 的预览内容可能为空。

## 修复

- `web/src/App.vue` 在上传成功后调用 `selectResource`。
- 由统一详情流程重新读取服务端资料，并同时加载安全文本预览、标签建议和处理任务记录。
- 保留上传成功提示和列表刷新，不改变原件保存、权限校验或文件类型白名单。

## 验证

- `go test ./...`
- `go vet ./...`
- `gofmt -l .`
- `cd web; npm run build`
- 浏览器隔离环境：登录后点击“添加资料”，通过 file chooser 注入自造 TXT，确认上传成功、详情打开且预览正文可见。

## 取舍与遗留

详情加载会在上传接口成功后多发一次受权限保护的资料详情请求，换取上传入口与列表点击入口使用同一套数据加载逻辑，避免两套状态同步规则。操作系统原生文件对话框的视觉行为不在自动化验收范围内。
