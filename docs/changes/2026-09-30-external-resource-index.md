# 外部资源索引首个可用切片

- 日期：2026-09-30
- 目的：从 `docs/roadmap.md:60` 后续继续推进 P0，使未上传的网盘、网站和本地资料也能整理与找回。

## 范围与取舍

- 新增 `010` 迁移、独立 GORM 仓储、Service、Gin 卡片 CRUD 接口与 Vue 独立面板；支持标题、位置、类型、版本、标签、备注及人工状态。
- 卡片与站内文件分离，避免无原件的卡片误入处理任务、原件下载或备份范围。所有查询由会话归属限定，更新标签用数据库事务。
- 地址只保存为纯文本，不自动请求第三方位置；重复地址不自动删除。统一搜索、粘贴预填、收件箱和手机号注册依旧是后续任务。
