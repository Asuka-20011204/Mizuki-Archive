# 2026-09-29 · 前台分屏导航与隐私说明

## 目的

将前台介绍从连续长页改为可直达的独立视图，强化项目与联系入口；让访客在登录前看清资料处理与隐私边界，而不是凭“私有”字样误认为没有任何泄露风险。

## 范围与取舍

- 首页、产品、原则、隐私、联系、登录使用 hash 导航切换；刷新与浏览器前进/后退保留视图。
- 联系页公开 GitHub、博客与 QQ 3178203745，QQ 号码可以复制；页脚提供显眼的联系与隐私入口，不虚构邮箱。
- 隐私页说明当前未开放访客注册或上传、多用户隔离尚未验收、登录后保存原件与元数据、会话 Cookie、派生内容与备份边界。只描述已核对的产品行为，不宣传“零泄露”或将页面当作完整法律政策。
- 没有更改认证、上传或删除的后端实现。手机窄屏可滚动阅读独立隐私页；不会变成从首页向下寻找联系内容的长页。

## 验证结果

- `npm run build --prefix web`：通过，包含 Vue 类型检查与 Vite 生产构建。
- `git diff --check -- web/src/App.vue web/src/styles/login.css web/src/styles/motion.css web/src/styles/responsive.css`：无空白错误。
- 浏览器：1440×900 的隐私页完整显示，页面无纵横向溢出；390×844 和 320×568 无横向溢出，隐私说明在窄屏可纵向阅读。
- `#privacy` 刷新后仍直达隐私页，从隐私页进入联系页并使用浏览器后退可返回隐私页；前台导航与页脚入口均可访问。

## 遗留风险与下一步

- 当前删除接口软删除元数据并尝试移除原件，派生文件和现有备份的统一清理期限尚未实现；在开放他人上传前必须落实删除、保留及事件响应机制，并由合适的法律专业人员审阅正式隐私政策。
- QQ 是公开联系渠道，不应发送密码、文件原文或其他敏感信息。
