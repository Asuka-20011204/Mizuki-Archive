# 2026-09-29 · 图片与 PDF 详情预览修复

## 问题

图片上传后详情预览容器限制了高度，但内部图片没有设置等比约束，宽高比异常时会撑满或显示不完整。PDF 详情接口此前明确拒绝在线预览，只能下载原文件。

## 修复

- 图片预览内部 `<img>` 使用 `object-fit: contain`，在固定预览区域内完整显示，不裁切原图。
- 登录用户可通过受会话保护的预览接口以内联方式读取 PDF，前端使用浏览器原生 PDF 查看器展示。
- 原文件下载接口仍使用 `attachment`，不改变下载安全边界。
- 新增 PDF 内联响应回归测试。

## 验证

- `go test ./internal/controller ./internal/service ./internal/processing`：通过。
- `npm run build --prefix web`：通过。
- `git diff --check`：通过。
- 合成浏览器已确认 PDF iframe 入口出现；重启 API 后才能看到最新内联响应。

## 遗留

- 浏览器原生 PDF 查看器的具体工具栏由浏览器决定，不同浏览器视觉可能不同。
- 本轮还包含 V5 并发控制与本地 Vite 地址修复；提交前分别核对差异、测试和敏感文件，不推送远端。
