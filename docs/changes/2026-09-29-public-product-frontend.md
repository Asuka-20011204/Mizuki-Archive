# 2026-09-29 · 前台产品介绍与资料库视觉增强

## 目的

把未登录状态从单一登录卡片升级为清晰的产品介绍入口，同时让登录后的资料库拥有更丰富的品牌叙事和状态反馈，接近企业服务网站的完整感，而不是通用后台模板。

## 范围

- 前台新增产品定位、管/找/处理能力介绍、隐私边界说明和登录入口。
- 使用纯 CSS 构建资料卡片、索引轨道和档案视觉，不引入第三方图片、字体或运行时依赖。
- 登录后的欢迎区增加档案宣言和当前视图状态摘要；摘要只基于已加载数据，不伪造整库统计。
- 增加桌面、窄屏布局和减少动效偏好下的降级样式。

## 取舍

- 宣传内容不读取任何私有资料，只有认证成功后才渲染资料库和状态数字。
- 不新增后端接口，不改变上传、检索、预览、处理和权限逻辑。
- 继续保持明亮、编辑化的视觉语言，使用少量暖色作为强调，避免堆叠统计卡片和通用渐变。

## 验证结果

- `npm run build --prefix web` 通过，包含 `vue-tsc --noEmit` 和 Vite 生产构建。
- `git diff --check` 未发现实际格式错误；换行提示为 Git 的平台转换提示。
- 本地 Vite 预览已在 `http://127.0.0.1:5175/` 检查，移动窄屏下可见宣传内容、资料卡片和登录入口。

## 遗留风险

- 真实登录后的资料库宽屏视觉仍需结合实际资料量和浏览器窗口尺寸做一次人工回归。
- 本轮没有新增前台路由；宣传入口与登录表单仍在同一页，适合当前多用户、各自私有资料空间的产品定位。
## 本轮追加

- 顶部导航改为纯文字链接，保留产品、原则、登录和 GitHub 入口，不使用按钮胶囊。
- 前台增加项目原则、使用边界和原件/处理结果关系说明，减少只有视觉而缺少信任信息的问题。
- 页脚加入 GitHub 项目与博客/联系入口；博客地址为 `http://admin.asuka2001.cloud/`。
- 前台 CTA 改为带细线和箭头的文字行动入口，保持高端、克制的企业服务网站观感。
