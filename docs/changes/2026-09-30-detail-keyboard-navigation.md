# 详情键盘切换与当前页导航

- 日期：2026-09-30
- 目标：减少在列表与文件详情之间反复打开、关闭的操作，同时保留编辑、键盘和鉴权边界。

## 范围与取舍

- 主列表、最近查看、统一搜索、待整理、已整理及归档入口在打开文件时携带当前页文件序列；详情仅在该序列中前后切换，不自动加载未请求的页面或其他账号资料。服务端仍按会话重新获取每项详情，缺失/越权不替换当前文件。
- 详情标题区提供上一项/下一项按钮和页内位置，左右方向键切换、Esc 关闭、D 触发同源鉴权下载链接；编辑框中的方向键和 D、组合键及输入法组合期间保留原生行为，Esc 仍关闭详情。PDF 内置查看器拥有独立键盘焦点，仍可用可见按钮操作。
- 未保存的名称或标签草稿在切换前要求确认；切换失败时保留当前详情并展示错误。补齐对话框标题的可访问名称，首开和关闭仍沿用焦点管理。

## 验证

- 新增邻项/缺失/边界用例后，`npm --prefix web test`：13 项通过；`npm --prefix web run build`：TypeScript 检查与 Vite 构建通过。未修改后端；浏览器登录后的焦点、下载和 PDF 行为尚未手动验收，不把组件构建通过当作浏览器验收。

## 风险与下一步

- 当前列表页边界不支持自动翻页；浏览器原生 PDF iframe 内无法由父页面捕获快捷键，用户可先将焦点移回标题区再操作。多账号页面、快速连按以及未保存编辑的交互仍需真实浏览器核对。
- P0 批量操作的登录态浏览器验收和后续 P1/P2 路线图任务保持未完成，不随本轮键盘功能自动勾选。
