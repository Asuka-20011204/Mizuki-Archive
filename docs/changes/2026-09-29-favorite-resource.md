# 2026-09-29 · 资料收藏编辑闭环

## 目标与用户影响

按 V1 路线图增加手动整理的最小能力：登录后在详情中收藏/取消收藏，列表标出已收藏资料。刷新或重新打开后以 MySQL 中的状态为准；不实现标签、收藏筛选或删除。

## 范围与取舍

- `PATCH /api/resources/:id/favorite` 接收 `{"favorite":true|false}`，复用私有路由的数据库会话与 Origin 校验；限制 JSON 体积、拒绝缺失/多段/未知字段，不返回内部数据库错误。
- Service 检查资源 ID，Repository 用 GORM 更新已有 `favorite` 字段并查询元数据；即使 MySQL 对重复同值更新报告零受影响行，仍按资源是否存在判断结果。无须变更表结构或迁移。
- Vue 的详情按钮用明确文本与 `aria-pressed` 表示状态；保存期间用 `aria-disabled` 和函数守卫阻止重复提交，但保留键盘焦点。只在成功后更新列表与详情，失败在抽屉提示。详情对象更新不应重复抢焦点。
- 选择显式设置而不是“切换”请求，便于请求重试。写入成功但后续读取失败可能使客户端看到错误、数据库却已更新；再次提交相同布尔值仍安全。现为单管理员；并发客户端设置不同值时以数据库最终写入为准，不承诺跨请求的版本冲突检测。
