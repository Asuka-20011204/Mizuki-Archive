# 2026-09-30 · 前台产品视觉重构

## 目的

去掉前台的纸张、档案卡片和旋转拟物感，让公开页面与后台资料库使用同一套产品基础语言，同时保留企业宣传页需要的留白、层级和品牌识别度。

## 范围

- 前台背景、导航、首页展示区、产品/原则/联系/隐私页和登录面板统一为浅灰蓝背景、白色工作面、蓝绿色强调色和清晰边界。
- 去掉公开页的大圆环装饰、玻璃模糊和旋转卡片的视觉表现。
- 将首页展示卡的持续动效改为不旋转的轻微垂直漂移，避免动画重新产生纸片倾斜感。
- 保留现有 hash 页面跳转、登录流程、联系入口和隐私说明，不改变业务接口。

## 取舍

- 继续参考 Sakurairo 的空间、文字导航和动效节奏，但不复制主题源码、资源或具体页面结构。
- 前台不复用后台固定侧栏；两者共享色彩、边界和信息面板语言，分别承担宣传解释与资料操作职责。
- 不引入新的动画库、图片资源或后端接口，降低部署和维护风险。

- 未改变后台已有未提交功能；本次提交只包含前台视觉与设计记录文件。
