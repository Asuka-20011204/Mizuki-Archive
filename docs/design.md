# 界面方向（设计草案）

> 统一搜索面板沿用 Sakura 系参考的轻白色表面、柔和阴影和圆角，但仅复用项目自有颜色变量与按钮组件，不复制下载主题源码或资产。桌面双栏把“已上传文件”和“外部卡片”明确分组；移动单栏显示，搜索标签、空状态、网络错误和分页按钮均为文本可读且键盘可聚焦。搜索命中已提取正文仅显示文件信息，不把全文渲染成不可信 HTML；点击文件打开现有详情，点击卡片进入现有编辑表单。

> 检索视图使用来源/类型/标签/整理状态的显式表单、可命名保存和可键盘操作的视图列表；应用视图时重新检索，删除前说明仅删除视图、不删除资料。移动端筛选区与保存表单改为单列，错误/成功使用文本消息，不依赖颜色或悬停传达状态。

> V4 在资料库上方加入简洁的“最近查看”胶囊入口：只展示存在且当前管理员可访问的资料，最多五项，服务端最多保留二十项。Redis 故障时隐藏该区块，主列表仍从 MySQL 读取；沿用 Sakurairo 的柔和白色层次，不复制主题代码和素材。

浏览器隔离库已验证最近查看会在打开资料后出现，Redis 停止时区块隐藏但主资料列表保持可用。删除时先移除本地条目并使在途最近访问请求失效，随后从服务端重新读取；退出登录会清空缓存于组件中的资料。

## 参考与边界

主要视觉参考是本地下载目录中的 Sakurairo（`style.css` 标注 3.0.11，属于 Sakura 系）。2026-09-29 的改版在大量参考主题的版式与动效手感的同时，保持资料管理产品的交互边界。

### 当前实现映射（V1 首个切片）

当前 `web/src/App.vue` 与 `web/src/styles/` 实现：登录页以宽幅产品展示区承接第一眼，使用后台同系的浅灰蓝背景、白色工作面、蓝绿色强调色和清晰边界；资料库以悬浮胶囊式顶栏、浅色封面、浮层类型筛选和一块集中呈现的白色列表为主，保留搜索、上传、单击打开资料检查器与下载入口。不恢复固定工作台侧栏，也不把每份资料拆成独立小卡。资料检查器参考 Windows 属性面板和企业资料系统，桌面端采用“内容主区 + 属性侧栏”的双栏结构，移动端切换为全屏单列；类型筛选在窄屏显示短标签；退出入口始终位于顶部。样式按基础、登录、资料库、动效、响应式五类拆分，顺序由 `web/src/main.ts` 导入。

已登录后台采用分区式信息架构：`文件资料` 负责上传与文件列表，`查找` 负责跨文件/外部卡片检索，`整理` 下分 `待整理`、`已整理`、`归档`，另有 `外部资源` 和 `专题`。各分区通过 hash 地址直达并支持前进/后退；首次访问后保留已打开组件，避免切换时丢失编辑表单草稿。详情检查器仍是全局模态层，可从文件、搜索、收件箱和专题条目打开。

为了私有资料库的隐私边界，前端不向第三方字体 CDN 发请求；当前使用本机可用的无衬线字体回退。若后续引入字体，先确认许可证、按需自托管并控制包体积。

目前覆盖名称与已提取正文的关键词检索、四类文件上传、下载、收藏、展示名称编辑、手动标签、标签筛选、删除和详情操作；列表显示收藏与标签，标签保存采用明确的整体替换，删除前有二次确认。图片支持内联预览，TXT/Markdown 以受限纯文本预览，PDF 明确提示下载。详情抽屉已有初始焦点、Tab 循环、Esc 关闭和关闭后焦点恢复；网络失败时保留输入内容，便于修正后重试。动效、空状态、窄屏布局和减少动态效果规则已集中在样式层；V1 真实资料回归结果记录在 `docs/changes/2026-09-29-v1-acceptance-and-recovery.md`。

参考依据不只 README：查阅了下载包 `style.css` 中的封面/导航/列表/输入视觉模式，以及 `css/animation.css` 的入场节奏，并对照本地 Sakurairo 设计规范中的组件和动效索引。具体借鉴宽幅封面、悬浮半透明白面、胶囊导航、少量柔和阴影、0.4 秒交互和 0.5–0.8 秒入场的节奏；没有照搬主题的全局 `transition: all` 或昂贵的全屏模糊。Sakurairo 是 WordPress 主题，不是 Vue 脚手架；本轮没有直接复制其 CSS、JS、图标、插画、字体或图片。若将来确需复用源文件，先逐项核查 GPL 和第三方素材许可与再分发义务。

动效强化后，`web/src/styles/motion.css` 集中管理登录封面、资料库封面的分段揭示和环形饰物，筛选胶囊、列表行错峰入场、搜索/空状态切换、按钮/行悬停反馈及详情抽屉进出。动效与信息层级一致，搜索结果文字在整个容器水平居中；无结果可直接清除筛选。窄屏登录页不再让装饰字母挤压标题。动态装饰不承载业务信息，系统选择减少动态效果时静止展示所有内容。纯 CSS 与 Vue 内置过渡，不引入动画运行库或主题源文件。

## 产品信息架构

登录页的手机登录/注册标签与输入表单沿用既有白色浮层、可见焦点和文本错误反馈，号码和验证码使用适合移动键盘的输入模式。只在 `/api/auth/capabilities` 返回 `phone_verification: true` 时显示；当前未接入短信发送器，手机入口不出现，不以静态占位冒充可用功能。

手机号入口的产品范围是中国大陆 11 位号码（可带 `+86`）；不展示或暗示国际区号选择。真实短信发送器、签名模板与隐私要求确认前保持关闭。

未登录前台按首页、产品、原则、隐私、联系、登录切换独立视图，导航与页脚均可直达隐私说明；该页只披露当前部署的数据边界，不将视觉上的“私有”写成绝对安全承诺。窄屏需要滚动阅读说明正文，但导航切换不要求从首页纵向翻找。正式开放他人上传前应另行确认多账号隔离、完整隐私政策、备份保留、派生文件清理和事件响应流程。

- **资料库**：搜索入口、类型/标签筛选、按最近更新排序的资料列表；密度适中，文件类型、大小和时间可快速扫读。
- **外部资源卡片**：资料区新增独立索引面板和紧凑编辑表单，沿用白色浮层、柔和蓝绿和圆角体系；位置显示为文本而非自动打开的链接，状态用文字明确标出且只由用户维护。窄屏改单列，错误、加载、空状态都有文本提示。
- **归档与找回**：待整理收件箱提供明确数量和确认的归档按钮，旁边提供单次反向恢复提示；独立归档区分别列出文件与外部卡片，支持当前页选择（至多 50 项）、恢复和分页。复用卡片边框、柔和阴影及响应式双列/单列布局，显式展示加载、空状态和错误，不把“归档”画成删除或“撤销”画成无冲突回滚。
- **批量删除**：收件箱和归档区的危险按钮与恢复按钮分开，当前页选中项必须再次输入“删除 N”确认。成功后展示实际删除数量；清理原件或派生产物暂时失败时提示后台待清理数量，不让用户误以为整个批次可安全重试。没有页面撤销入口，不能用“回收站”指代归档区。
- **已整理批量入口**：在收件箱与归档区之间沿用白色轻浮层和双列分组，按当前账号已整理状态分别分页文件与卡片；勾选、详情/编辑按钮分开，翻页清空选择。提供退回待整理、标签、收藏、归档及不可撤销的删除；仅标签/收藏实际变化项显示一次反向恢复，并在执行前提示并发覆盖风险。窄屏双列改为单列，错误、空状态与数量反馈保留文字。
- **粘贴快捷收录**：在外部索引面板粘贴分享文字直接预填可编辑表单，并将焦点移至标题；预填提示明确“核对后保存”，不把粘贴动作伪装为已完成录入。解析失败保留原文供手动检查，保存成功后清空剪贴板原文的表单副本。
- **待整理收件箱**：在文件和外部资源面板前展示一块轻量收件箱，分别标注“站内文件”和“外部卡片”；按钮进入对应详情/编辑，再由用户明确标记“完成整理”。空、加载、错误与分页都有文字说明；完成整理不等于删除或保证链接可用。移动端切成单列。
- **批量整理**：每条资料提供可通过键盘操作的勾选框，当前页最多选择 50 项；确认对话框显示数量，成功后显示一次撤销按钮与明确的恢复状态，不用消失的 Toast 代替撤销。刷新或翻页清空选择，避免误操作其他页。
- **批量标签**：待整理收件箱沿用 Sakurairo 风格的白色轻浮层、柔和焦点和紧凑按钮；同页选择最多 50 项，输入一个标签并明确“添加/移除”，提交前确认数量；仅在确实变化后提供一次“反向恢复”，点击前明确提示可能覆盖其他设备后来的编辑，不能称为无冲突撤销。加载、空变化、错误和上限拒绝都使用文字反馈，窄屏操作区自动换行。
- **批量收藏**：沿用相同选择范围和键盘可操作控件，明确展示收藏/取消收藏两种目标；卡片列表还提供 `aria-pressed` 收藏按钮。提交前确认数量、无变化给文字提示，反向恢复前提醒并发覆盖风险；仅呈现服务端真实返回的状态，不根据点击乐观猜测。
- **登录入口**：以“验证码登录 / 注册新账号”作为主选项，普通用户与兼容管理员共用次级密码登录入口；邮箱和大陆手机号共用身份输入，按格式路由到已启用的发送器。注册在验证码后设置唯一用户名、密码及确认密码；验证不成功不创建用户。202 只表示请求受理，未知账号不会得到登录码；未接入短信时号码入口禁用并解释原因。切换流程或身份后清空旧码和提示，窄屏主选项保持单行无横向滚动。
- **资料详情**：单击列表行打开检查器，默认仅展示“预览与获取”（安全预览、属性、收藏、下载）；“整理与关联”集中展示名称编辑、笔记、标签和关联；“按需处理”展示手动任务、历史及产物，OCR 展开时可在当前分区对照原件。删除收进明确的“更多操作”；切换分区保留未保存草稿。窄屏按选中分区纵向排列，分区按钮可横向滚动。
- **PDF 阅读空间**：默认让 PDF 居中占据详情正文宽度与剩余高度；宽屏标题区将文件名与当前列表切换合并为一行，文件名超出时省略且保留完整悬停提示，窄屏换行。“内容/预览”仅作为语义化标题保留，不重复占用阅读空间；PDF 操作按钮单独成条。默认收起属性侧栏，从第一页请求整页适配；“显示属性栏”可切回双栏，下载入口始终可见。内置查看器最终缩放仍取决于浏览器实现，另提供同源鉴权的“新标签页阅读”以使用浏览器完整视口；移动端保持整屏弹窗，不让扩大规则挤压非 PDF 资料。
- **可携带清单**：资料工具栏提供明确写着“不含原件”的按钮；不使用误导性的“完整备份”文字。成功后才保存 JSON；限流或超量在页面显示可见错误，窄屏操作自动换行，真实浏览器体验仍待验证。
- **私有专题展页（设计中）**：延续现有白色轻浮层与柔和强调色，用封面、简介和分区目录建立阅读层次，不做公开博客首页。分区及条目提供上移/下移操作和当前序号，键盘、触屏均可用；站内封面走受权限保护的图片预览，不拼接文件存储路径。空专题、引用失效、保存中、失败和删除确认均有文字反馈；窄屏改为单列，长标题不能挤走操作按钮。参考 Sakurairo 的空间感而非复制其源文件或资源，最终浏览器验收前不宣称完成。
- **详情键盘切换**：标题区提供上一项、位置、下一项与可见快捷键提示；当前来源的已加载文件页才可切换，边界按钮禁用，不冒充跨页浏览。左右方向键和 D 不抢占编辑框按键，Esc 仍可关闭；PDF 内置查看器焦点独立，下载仍指向服务端鉴权接口。未保存草稿切换前确认，关闭后恢复打开位置的焦点。
- **最近使用/收藏**：帮助个人快速返回常用资料，不虚构社交动态或指标看板。
- **任务中心（V2）**：待处理、处理中、成功、失败分组；真实可解释的状态、文本/缩略图产物下载与预览、脱敏的失败原因，不伪造进度条。

手机端从检索和列表开始优先设计，详情采用可切换的预览/元信息区域。空资料库给出首次上传引导；搜索无结果给出清除筛选；上传失败展示可恢复操作。

## 视觉语言

- **关键词**：明亮、开阔、企业产品感、白色工作面、浅灰蓝背景、蓝绿色品牌色、清晰边界。前台可以借鉴 Sakurairo 的空间感、文字导航和动画节奏，但不再使用纸张、档案卡旋转、拟物圆环或全屏玻璃效果。
- **层级**：前台首页提供大尺度的产品展示区和清晰行动入口，产品/原则/隐私/联系页使用白色信息面板；后台继续负责资料效率，前台负责产品解释与信任建立。一块承载内容的白面板替代满屏同构小卡，不虚构指标或把资料库改成博客文章页。
- **系统化**：实现时以 CSS tokens 管理色彩、字阶、间距、圆角与动效；上传、筛选、下载、失败/成功等状态使用语义色，不单靠颜色传达。
- **动效**：前台页面按层入场，产品展示面板只做轻微垂直漂移、阴影变化和页面切换，不旋转内容面板；导航、行与按钮沿用主题偏柔和的 0.4 秒节奏，只过渡必要属性。尊重 `prefers-reduced-motion`，不使用持续飘落的粒子或全局过渡。
- **可访问性**：语义化结构、键盘可达、可见焦点、合适的文字对比度；上传进度/任务状态需要文本和辅助技术可理解的反馈。

## 先验证的页面

关联线索面板置于文件详情与外部卡片编辑页，采用列表、明确的“关联/解除”操作和当前账号的统一搜索；显示类型与名称，不用关系图暗示自动推荐或共享。窄屏保持可换行的搜索和按钮，错误、加载、空结果及解除后的资料保留提示都使用可读文本。真实浏览器的键盘焦点、详情跳转与窄屏仍待验证。

上线前在桌面与窄屏上继续检查长文件名、无预览文件、空列表、加载与错误状态，以及真实后端下的上传、标签、预览、删除和下载。V1 暂无任务中心，不以视觉占位冒充功能；页面视觉可继续依据实际使用反馈调整。
