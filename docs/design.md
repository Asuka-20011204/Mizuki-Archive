# 界面方向（设计草案）

## 参考与边界

用户指定本地下载目录中的 2026 年 9 月版本；其 `style.css` 标注版本 3.0.11。

### 当前实现映射（V1 首个切片）

当前 `web/src/App.vue` 与 `web/src/styles/` 实现：登录页的纸张叠层与暖杏色光晕；资料库的柔和侧栏、阅读型标题、类型筛选、搜索、上传、资料列表、详情抽屉和下载入口。配色由暖纸白、浅杏、陶土色与低饱和状态色组成；这是项目独立设计，并未复制主题 CSS/图片。样式按基础、登录、资料库、响应式四类拆分，顺序由 `web/src/main.ts` 明确导入。窄屏把资料类型导航移到底部，系统减少动态效果时关闭过渡。

为了私有资料库的隐私边界，前端不向第三方字体 CDN 发请求；当前使用本机可用字体与衬线回退。若后续引入字体，先确认许可证、按需自托管并控制包体积。

目前只覆盖文件名检索、四类文件上传与下载。标签、收藏操作、安全预览与任务中心仍在路线图后续阶段；现有详情页会明确提示预览未提供。详情抽屉已加入初始焦点、Tab 循环、Esc 关闭和关闭后焦点恢复；仍需在登录后实际操作验证。已在浏览器打开并查看桌面登录页（约 1267×713），纸张层次、表单和文字布局可见；窄屏、资料库登录后页面与长文件名仍待实测，不能以写完 CSS 代替完整验收。

本地参考：下载目录中的 `Sakurairo-main`（2026 年 9 月版本）。参考其柔和色彩、轻盈层次与有温度的阅读氛围；这是 WordPress 主题，不是本项目的前端脚手架。其源码标注 GPL v2 或更高版本；**仅借鉴设计观感**，不复制 CSS、图标、插画、字体或其他素材到本项目。若将来确需复用资源，先逐项核查版权/许可证与再分发要求。

## 产品信息架构

- **资料库**：搜索入口、类型/标签筛选、按最近更新排序的资料列表；密度适中，文件类型、大小和时间可快速扫读。
- **资料详情**：左侧/主区安全预览，旁侧展示标签、来源、时间、文件操作；后续加入处理结果与历史，不让任务状态喧宾夺主。
- **最近使用/收藏**：帮助个人快速返回常用资料，不虚构社交动态或指标看板。
- **任务中心（V2）**：待处理、处理中、成功、失败分组；真实可解释的状态、重试入口、脱敏的失败原因，不伪造进度条。

手机端从检索和列表开始优先设计，详情采用可切换的预览/元信息区域。空资料库给出首次上传引导；搜索无结果给出清除筛选；上传失败展示可恢复操作。

## 视觉语言

- **关键词**：纸张、档案、轻柔樱色、克制的玻璃质感。以高可读性的浅色阅读表面为主；装饰只在导航、封面和状态点缀，不降低正文对比度。
- **层级**：将搜索与资料内容作为主角；用标题尺度、留白、细边界和少量柔和阴影区分信息，而不是满屏同构卡片。
- **系统化**：实现时以 CSS tokens 管理色彩、字阶、间距、圆角与动效；上传、筛选、下载、失败/成功等状态使用语义色，不单靠颜色传达。
- **动效**：只做简短且有意义的反馈；尊重 `prefers-reduced-motion`，避免对所有元素设置全局过渡或持续模糊。
- **可访问性**：语义化结构、键盘可达、可见焦点、合适的文字对比度；上传进度/任务状态需要文本和辅助技术可理解的反馈。
