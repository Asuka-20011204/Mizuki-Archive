# 产品定义（V1 实施基线）

更新：2026-09-30。产品定位保持为面向多个独立用户的个人数字信息管理系统；“已实现”只以代码、测试和实际验收记录为准。

## 一句话定位

Mizuki Archive 是面向多个独立用户、用于长期管理个人数字资料的资料库：将 PDF、图片、Markdown/TXT 统一收纳、整理、检索，并在需要时对资料做可追踪的后台处理。

已增加独立的外部资源索引：只保存用户提供的位置和线索（网盘、网站或本地路径），不把站外原件当成已上传资料；各用户分别维护自己的卡片。

## 用户与问题

- 产品定位：面向多个独立用户的个人数字信息管理系统；每个用户管理自己的资料空间，首位用户是项目作者本人。多人不是共享同一资料库，默认禁止跨账号读取。
- 使用规模目标：系统不是“只有作者自己使用”的单用户工具，而是允许多个独立用户长期使用的资料服务；高并发、高可用是项目的工程目标，必须通过多实例、任务并发、依赖故障和混合负载测试逐步证明。
- 问题：散落在目录里的文件难以按主题找回；预览/文本提取等处理耗时，直接放在上传请求中会拖慢交互；处理结果与失败原因容易丢失。
- 产品价值：不是重新实现云盘同步，而是把**资料的上下文、查找和处理历史**留在一起。

## 核心流程

1. 上传资料 → 校验并保存文件 → 记录名称、类型、大小、哈希、时间等元数据。
2. 人工设置标签/收藏 → 按关键词、类型、标签和时间筛选 → 查看详情或下载原件。
3. 请求处理 → 返回任务标识 → 后台处理 → 在资料详情/任务中心查看状态、结果和失败原因。

站外资料走另一条流程：创建卡片 → 补充类型、版本、标签和备注 → 手动维护可用/失效状态 → 通过标题或位置找回。服务器不探测位置，也不代表已备份外部文件。

可选快捷录入：在浏览器中粘贴链接或网盘分享信息，自动预填卡片的标题、位置、类型和提取码；用户可以修改，必须主动确认保存。非法协议、不完整信息和含 URL 登录凭据的粘贴内容不自动收录。

待整理收件箱统一展示尚未标记完成的站内文件和外部卡片：创建默认待整理，用户可打开文件详情或编辑外部卡片补齐线索，再手动标记已整理；不强迫上传时填完标签。外部链接“未核对/可用/失效”等状态独立于资料“待整理/已整理”。首次升级的历史资料也会出现在收件箱，旧资料不能被默认为已整理。

批量整理只作用于当前页用户明确勾选的至多 50 项；提交前确认数量，成功后可一次撤销回“待整理”。任何条目不属于当前账号或已不存在，整批不修改；不涉及文件删除、外部链接状态或跨账号共享。批量加标签、收藏、归档及删除仍是未实现规划。

新文件保存后按原件 SHA-256、外部 HTTP(S) 卡片保存或编辑后按规范化地址，提示同账号已有的疑似重复资料。提示不会阻止用户保存或自动删除；不访问外部地址，不比较本地路径，也不会显示别人的卡片。重复查询不可用时返回明确的“暂不可用”，不能把无提示当成没有重复。

统一搜索由一个关键词入口查询当前用户的已上传文件（文件名、原文件名、标签、已提取正文、私人笔记及摘录/来源）和外部卡片（标题、位置、类型、版本、标签、备注）。两种来源分别展示、每类独立分页，不把外部卡片描述成已上传文件。匹配正文或笔记时只返回原件元数据，不在搜索结果中回传私人全文。文件详情可逐条保存私人笔记；PDF 页码由用户手动填写而不是自动从预览提取，每文件最多 100 条。外部卡片现有备注仍是独立字段。

保存的检索视图记录当前用户的关键词、来源（文件/卡片）、类型、标签和整理状态组合；没有关键词时至少要有类型、标签或整理状态条件。视图名称在同一账号内唯一、每账号至多 30 个；打开时实时查询，不缓存匹配结果或复制正文；删除视图不会删除原件。此处“状态”指待整理/已整理，不代表外部链接有效性。

关联线索允许把同一账号的文件与外部卡片两两连接；两端都能看到对方当前名称并从详情跳转。每项最多 100 条，重复或自关联不允许；解除关系不删除资料，删除资料时清理关系。跨账号资料不能关联或通过列表被发现，关系图与自动推断不在当前范围。

V1 实现前两步；V2 已支持手动提取 PDF、TXT、Markdown 文本及生成图片缩略图。详情可查看任务状态、失败摘要与缩略图，下载原件和派生产物；成功提取的正文可参与关键词检索。扫描版 PDF 的 OCR、自动分类及所有 PDF 版式的提取质量不在承诺范围内。

## V1 范围与验收

| 能力 | 首期验收口径 |
| --- | --- |
| 用户访问 | 邮箱验证码注册/登录与可撤销数据库会话；每个用户只能访问自己的资料；密码登录在迁移期间保留。 |
| 上传 | 仅允许 PDF、PNG/JPEG/WebP、Markdown、TXT；单文件上限 50 MiB；服务端校验体积与类型，失败不留下可访问的半成品。 |
| 整理 | 支持展示名称、手动标签、收藏和删除；标签替换幂等，删除先软删除并解除标签，再清理原件。 |
| 查找 | 可按名称关键词、类型、标签和时间分页筛选；有空结果与异常状态。 |
| 查看 | 支持元数据、图片预览、1 MiB 内的 TXT/Markdown 安全文本预览和原件下载；PDF 暂提示下载，不做在线渲染。 |

## 不做与待确认

- 首期不做：网盘同步、跨账号协作/共享、社交、AI 自动分类、音视频、Office 全格式、OCR、分布式微服务和 Kubernetes 生产部署。这里的“不做”表示暂不开放相互协作，不表示系统只允许一个用户。
- V1 已确定：本地受控文件目录与 MySQL 元数据必须成套备份，恢复必须在隔离数据库和隔离目录中校验哈希；Markdown 只按安全文本预览，不执行 HTML/脚本。
- 待确认：正式部署的异地备份位置、首个异步处理类型的输出质量标准、是否需要全文搜索。
- 设计中的吞吐与性能只作为后续实测假设，不能作为简历中的既成成绩。
