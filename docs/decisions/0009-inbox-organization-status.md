# ADR 0009：整理状态与链接状态分离

- 状态：采纳（2026-09-30）
- 背景：新上传文件和新建外部卡片需要先进入待整理收件箱；外部卡片现有 `status` 表示链接是否可用，不能拿来表达整理进度。
- 决定：两个资源表各增 `organization_status`，默认 `pending`，人工完成后为 `organized`；旧资料同样待整理，避免臆断已有条目已分类。外部 `status` 的 `pending` 在界面显示为“未核对”，只表示链接未核查。两类待整理条目在独立服务里按用户分页读取。
- 安全与一致性：HTTP 只接收目标状态，Repository 每次写入必须限定服务端用户 ID 与条目 ID，重试同状态无副作用；已删除文件不在待整理列表。架构不改变上传原件、派生物或外部地址。
- 代价：首次迁移老用户会看到较多待整理条目。后续批量整理和跨来源统一检索需要另行设计，不能把“整理完成”误写成“外部链接已验证”。
