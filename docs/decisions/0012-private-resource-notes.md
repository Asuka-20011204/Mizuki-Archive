# ADR 0012：私人笔记按文件与账号存储

- 日期：2026-09-30
- 状态：已采纳

## 背景与决定

卡片备注无法表达 PDF 页码或同一文件的多条摘录。建立独立 `resource_notes` 表，笔记只依附已上传的站内文件；`user_id` 由服务端会话写入，并与 `resource_id` 一起限定每次读写。PDF 页码可空，只对 PDF 有效；摘录、正文与来源均为用户手写的纯文本，绝不自动从 PDF 或外部链接提取。

每文件最多 100 条：创建事务锁定文件行并检查现有数量，列表有固定上限。搜索仍以文件为结果单位，通过当前用户/文件范围的 `EXISTS` 匹配笔记内容、摘录、来源，不在结果列表返回笔记全文。单项或批量删除文件时，在同一事务内软删除文件并硬删除笔记行；直接物理删除文件时外键级联清除笔记。已经生成的数据库备份仍可能保留旧内容，备份保留周期另作专项。

## 代价与后续

目前使用 MySQL `LOCATE` 子串匹配；在多用户大规模数据下需要以实际负载评估全文索引或外部搜索服务，不承诺固定搜索延迟。外部卡片仍使用原有备注字段，跨资料关联和可携带导出属于路线图后续任务。正式数据库迁移前必须先备份；备份中的笔记不受在线删除影响。
