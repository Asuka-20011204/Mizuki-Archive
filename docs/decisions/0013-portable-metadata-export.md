# ADR 0013：可携带元数据导出不等于备份

- 日期：2026-09-30
- 状态：已采纳

## 背景与决定

个人资料库需要能把卡片、标签、笔记和关联带离系统，且不能把外部位置误写成已经保存的文件。提供当前账号的 `mizuki-archive-portable` v1 JSON 清单：文件元数据（保留 ID、名称、原始名称、类型、大小、摘要和标签）、外部资源卡片及标签、私人笔记与关联两端 ID。归档条目仍属于当前账号；软删除文件及其笔记不导出。上传原件、派生产物、短信/邮件验证码、会话和数据库存储路径均不在清单中。此格式可离线阅读和交叉引用，**未提供自动导入**，也不是备份恢复格式。

Repository 在只读 `REPEATABLE READ` 事务中按用户取同一快照，并用快照中可见条目过滤关系；Service 写入版本/时间并在发送前校验 JSON 大小。每次最多 5000 份文件、5000 张卡片、10000 条笔记与 10000 条关联，结果至多 32 MiB；超限返回 413，不静默丢弃。Controller 每用户每分钟最多两次，本机同时最多两个导出；前端提供不含原件的明确提示。附件内容需由用户自行安全保存。

## 代价与后续

导出在服务端短时保留完整数据及 JSON 缓冲，限制内存和请求时长；超出上限的资料库需要后续评估分卷/后台流式导出，而不能用截断数据冒充完成。离线 JSON 只作为可携带清单，完整迁移仍须通过数据库备份与原件目录/对象存储恢复。版本化格式如增加字段必须保留兼容策略；浏览器下载、窄屏提示与大规模容量仍需实测。
