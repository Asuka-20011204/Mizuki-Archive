# ADR 0005：RabbitMQ 任务投递采用事务 Outbox

- 状态：已采纳（2026-09-29）。
- 场景：个人资料的 PDF/TXT/Markdown 文本提取及图片缩略图由用户手动触发；HTTP 不同步处理耗时任务，MySQL 与 Broker 不共享事务。
- 决策：API 在 MySQL 同一事务写 `processing_jobs` 和 `processing_outbox`；发布者领取短租约、等待持久消息发布确认，再标记事件已发布。Worker 凭任务 ID 回库领取，成功后 ACK；异常有限重发并隔离，定期补偿未投递或丢失事件。数据库模式保留为回滚开关。
- 一致性：至少一次而非恰好一次；进程崩溃或确认丢失允许重复消息，数据库状态/租约拒绝重复完成。次数耗尽明确失败；消息不得含资料内容、文件名或路径。
- 代价：额外表、扫描及连接状态；修复事件可能重复投递。无压测数字前不声称吞吐提升。
