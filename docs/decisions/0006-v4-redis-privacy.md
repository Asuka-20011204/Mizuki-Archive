# ADR 0006：Redis 仅缓存可重建数据

- 状态：已采纳（2026-09-29）。
- 决策：Redis 存标签建议、任务详情/短列表、最近访问资源 ID、哈希化 IP 限流计数；不存原件、完整提取正文或会话凭据。详情与下载仍回源 MySQL，私有资料列表不缓存，以避免删除后并发回填旧元数据。
- 安全边界：单管理员会话仍由 MySQL 决定；Redis 故障时降级查询和本地登录失败次数限制，跨进程限流不再保证。最近访问有 20 条上限、90 天到期；删除后尝试清理成员，返回前回查 MySQL。
- 代价：列表维持 MySQL 压力，缓存失效失败可令标签/任务状态短暂陈旧。V7 固定数据集再比较收益与一致性成本，不虚构数字。
