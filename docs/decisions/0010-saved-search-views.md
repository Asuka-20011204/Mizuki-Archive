# ADR 0010：检索视图只保存条件

- 日期：2026-09-30
- 状态：已采纳

## 背景与决定

用户需要复用“尚未整理”等筛选组合。保存命中结果或派生正文会产生过期副本，并使删除、权限隔离和备份范围更难审计。因此 `saved_search_views` 只保存当前用户的关键词、来源、类型、标签和整理状态；打开视图必须重新走受限流保护的私有搜索。浏览器只把已保存条件带回查询入口，不能指定账号 ID。

同账号名称唯一、最多 30 个视图，创建事务锁定账号行，删除视图不删除资料。`014` 使用 `CREATE TABLE IF NOT EXISTS`，迁移版本登记中断可重试；运行账号不能替代迁移账号执行 DDL。

## 代价与后续

检索结果会随资料变化，视图不提供“当时的快照”；模糊匹配仍有扫描成本，必须保留账号限流与查询超时。数据增长前对真实规模测耗时，再评估全文索引和更精细的状态/类型分类。
