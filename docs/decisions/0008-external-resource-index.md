# ADR 0008：外部资源使用独立卡片

- 状态：采纳（2026-09-30）
- 背景：路线图 P0 要收录网盘、网站和本地位置；这些资源没有本站原件，不能套用上传文件的存储键、哈希和任务不变量。
- 决定：独立 `external_resources` 与 `external_resource_tags` 表、独立仓储接口和 Service；Owner 从会话注入，所有数据库读写按用户过滤。地址只作文本，既不自动探测也不自动下载；状态由用户手动选择。
- 代价：站内文件与外部卡片暂时分开检索；跨来源统一搜索和疑似重复提醒是后续 P0 任务。未验证的外部位置不代表备份或站点可用。
- 安全：创建和更新限制请求体与字段长度；标签沿用已有规范；不把用户地址交给后端 HTTP 客户端或内联执行的前端 HTML。
