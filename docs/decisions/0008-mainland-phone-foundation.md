# ADR 0008：大陆手机号认证基础与供应商开关

- 日期：2026-09-30
- 状态：基础已实现；真实发送待决策

## 决定

面向中国大陆手机用户，接受严格的 11 位号码或 `+86` 前缀并统一保存为 `+86` 加 11 位；不按固定运营商号段作硬编码白名单。`users.phone` 为独立可空唯一索引，旧邮箱用户不会自动绑定同号；新手机号注册创建独立账号。验证码挑战与邮箱分表，使用 HMAC 摘要、重发冷却、过期与错误次数限制、事务性一次性消费。Controller 管 HTTP 和双层限流，Service 管身份流程，Repository 管 GORM/MySQL；View 仅按服务端能力显示入口。

未确定短信供应商、签名模板、费用预算和适用隐私约束前，不写假发送器，不加可误开的环境开关；`cmd/server` 不注入 `PhoneAuth`，`phone_verification` 始终为 `false`。选定供应商后须做官方 API 适配和真实号码小额验收，审计速率、预算、账户枚举、短信轰炸、日志和个人信息留存；旧邮箱用户绑定手机需单独已登录的双重验证流程。

## 迁移与回退

`012` 在迁移锁下分别检查列和唯一索引并创建挑战表，兼容 DDL 后中断重试。上线前备份并用隔离库验证；当前未启用发送，回退 API 版本可不删除新增列/表，**不要**用回退动作删除任何用户数据。
